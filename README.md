# استعلام موعد تحديد المستوى – أروقة القرآن الكريم (دفعة نوفمبر 2026)
- النشر: GitHub → Settings → Pages → Deploy from branch (main / root).
- لتحديث البيانات: `python3 build_data.py ملف.xlsx` ثم ارفع `data.json` الجديد.
- الأرقام القومية مخزّنة كـ SHA-256 مُقتطع (وليست نصًا صريحًا) داخل data.json.
